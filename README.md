# gitgud9.github.io

Personal portfolio of **Javier Yeo**, ICT undergraduate at the Singapore University of Social Sciences (SUSS).

Live site: https://gitgud9.github.io/

## Featured projects

- **[Queuely](https://queuely-three.vercel.app)**: a real-time event queue system with QR join, live wait times, a staff portal and a public "Now serving" screen. Next.js, Supabase, Vercel. [Source](https://github.com/gitgud9/queuely)
- **[AI Event Assistant](https://queuely-three.vercel.app/assistant)**: a Gemini-powered chatbot that reads live queues and the event schedule through tool calls. [Source](https://github.com/gitgud9/queuely#ai-event-assistant)
- Game development (Unity, C#) and mobile app development (Firebase) projects from Temasek Polytechnic.

## Structure

- `index.html`: the whole site (one page)
- `custom.css`: styles
- `images/`: project screenshots
- `profile.jpg`: profile photo

Plain HTML and CSS, served by GitHub Pages from the default branch. No build step.
